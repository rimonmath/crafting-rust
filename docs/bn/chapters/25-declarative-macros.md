# ২৫. ডিক্লারেটিভ ম্যাক্রো (Declarative Macros)

## আপনি যা শিখবেন

- রাস্টে **মেটাপ্রোগ্রামিং (Metaprogramming)** কী এবং কীভাবে ম্যাক্রো কম্পাইল টাইমে স্বয়ংক্রিয়ভাবে কোড লিখে দেয়।
- সাধারণ রাস্ট ফাংশন কেন ডুপ্লিকেশন ও বয়লারপ্লেটের সব সমস্যা মেটাতে পারে না (নির্দিষ্ট সংখ্যক প্যারামিটার, সিনট্যাক্স অ্যানালাইসিসের অক্ষমতা, রানটাইম এক্সিকিউশন)।
- সি/সি++ এর টেক্সট-প্রতিস্থাপন প্রিপ্রসেসর (`#define`) এবং রাস্টের **হাইজিনিক (Hygienic) ও এএসটি-সচেতন (AST-aware)** ম্যাক্রো সিস্টেমের মধ্যকার মৌলিক পার্থক্য।
- **ডিক্লারেটিভ ম্যাক্রো (`macro_rules!`)**-এর গঠন ও অভ্যন্তরীণ মেকানিজম:
  - **ডেজিগনেটর (Designators)**: `$expr`, `$ident`, `$ty`, `$pat`, `$literal`, এবং `$tt`।
  - **রিপিটিশন প্যাটার্ন (Repetition Patterns)**: `$( ... ),*`, `$( ... ),+`, এবং অপশনাল ট্রেইলিং কমা `$(,)?` হ্যান্ডলিং।
  - একাধিক ম্যাচিং ব্রাঞ্চ দিয়ে কম্পাইল-টাইম ওভারলোডিং।
- মিনিস্টোরের জন্য কার্যকরী ডোমেন ডিএসএল (Domain-Specific Languages - DSL) তৈরি:
  - `product!`: এনাম ভ্যারিয়েন্টের শর্টহ্যান্ড ও ডিফল্ট মানসহ দ্রুত প্রোডাক্ট তৈরি।
  - `catalog!`: কমা দিয়ে সাজানো তালিকা থেকে একবারে ক্যাটালগ ইনিশিয়ালাইজ করা।
  - `cart!`: একাধিক সিনট্যাক্স স্টাইল (টুপল ও নেমড ফিল্ড) সমর্থনকারী কার্ট ম্যাক্রো।
  - `calculate_total!`: রিকার্সিভ ভ্যারিয়াডিক প্যাটার্ন (বেস কেস + ইনডাক্টিভ স্টেপ)।
  - `assert_in_stock!`: সুন্দর ও অর্থপূর্ণ এরর মেসেজসহ ডোমেন অ্যাসারশন ম্যাক্রো।
- **ম্যাক্রো হাইজিন (Macro Hygiene)** কী এবং এক্সপোর্টেড ম্যাক্রোতে (`#[macro_export]`) কেন **`$crate`** ব্যবহার করা বাধ্যতামূলক।

## আমাদের ম্যাক্রো কেন প্রয়োজন?

মিনিস্টোর তৈরি করার পুরো প্রক্রিয়ায় আমরা বারবার টেস্ট স্যুট, সিএলআই মেইন ফাংশন এবং সিডিং স্ক্রিপ্টে প্রোডাক্ট, ক্যাটালগ ও শপিং কার্ট তৈরি করেছি:

```rust
// প্রতিটি প্রোডাক্টের জন্য দীর্ঘ বয়লারপ্লেট কোড:
let p1 = Product::new(
    101,
    String::from("TECH-KEY-001"),
    String::from("Mechanical Keyboard"),
    ProductCategory::Electronics,
    15000,
    10,
);

let mut catalog = Catalog::new();
catalog.add_product(p1);
catalog.add_product(p2);
catalog.add_product(p3);

let mut cart = ShoppingCart::new();
cart.add_item(101, 2, 15000);
cart.add_item(102, 5, 1200);
```

যদিও এই কোডটি পরিষ্কার ও নিরাপদ, কিন্তু শত শত টেস্ট কেস বা ডোমেন সিনারিও লেখার সময় বারবার একই কাজ করা অত্যন্ত ক্লান্তিকর ও পুনরাবৃত্তিমূলক।

### সাধারণ ফাংশন কেন যথেষ্ট নয়?

আমরা কি এটি সাধারণ রাস্ট ফাংশন দিয়ে সমাধান করতে পারতাম? উত্তর হলো: পুরোপুরি নয়। কারণ:
১. **নির্দিষ্ট প্যারামিটার সংখ্যা (Fixed Arity)**: রাস্টে একটি সাধারণ ফাংশন সবসময় পূর্বনির্ধারিত সংখ্যক আর্গুমেন্ট গ্রহণ করে। আপনি এমন কোনো ফাংশন লিখতে পারবেন না যা কখনো ৩টি, কখনো ১টি, আবার কখনো ১০টি প্রোডাক্ট সরাসরি আর্গুমেন্ট হিসেবে নেবে (যদি না সেগুলোকে ভেক্টর বা স্লাইসে মুড়িয়ে পাঠান)।
২. **সিনট্যাক্স বোঝার অক্ষমতা**: কোনো ফাংশন সরাসরি `Electronics` আইডেন্টিফায়ার গ্রহণ করে সেটিকে `ProductCategory::Electronics`-এ রূপান্তর করতে পারে না। ফাংশন সবসময় কনক্রিট টাইপ প্রত্যাশা করে।
৩. **কম্পাইল টাইমে কোড না লেখা**: ফাংশন রানটাইমে এক্সিকিউট হয়। এটি কম্পাইল টাইমে নতুন টাইপ তৈরি করা, ট্রেইট ইমপ্লিমেন্ট করা বা কম্পাইলারের অ্যাবস্ট্রাক্ট সিনট্যাক্স ট্রি পরিবর্তন করতে পারে না।

### সি প্রিপ্রসেসর বনাম রাস্ট ম্যাক্রো

সি (C) বা সি++ (C++) ভাষায় ম্যাক্রো চলে `#define` দিয়ে, যা স্রেফ কাঁচা টেক্সট প্রতিস্থাপন করে:

```c
// বিপজ্জনক C ম্যাক্রো:
#define SQUARE(x) x * x

int result = SQUARE(1 + 2); // প্রতিস্থাপিত হয়: 1 + 2 * 1 + 2 = 5 (৯ নয়!)
```

কিন্তু রাস্টে ম্যাক্রো কোনো সাধারণ টেক্সট প্রতিস্থাপন নয়; এটি সরাসরি **টোকেন স্ট্রিম (Token Stream)** এবং **অ্যাবস্ট্রাক্ট সিনট্যাক্স ট্রি (AST)**-এর ওপর কাজ করে:

- এটি অপারেটরের অগ্রাধিকার (Precedence) পুরোপুরি মেনে চলে।
- এটি **হাইজিনিক (Hygienic)**: ম্যাক্রোর ভেতরে ঘোষিত ভ্যারিয়েবল কখনো বাইরের ভ্যারিয়েবলের নাম দুর্ঘটনাবশত ঢেকে (shadow) ফেলে না বা লিক করে না।
- ম্যাক্রো এক্সপ্যান্ড হওয়ার পর রাস্ট কম্পাইলার পুনরায় টাইপ-চেকিং সম্পন্ন করে, ফলে রানটাইমে ক্র্যাশ করার কোনো সুযোগ থাকে না।

## ডিক্লারেটিভ ম্যাক্রোর গঠন (`macro_rules!`)

রাস্টে ডিক্লারেটিভ ম্যাক্রো তৈরি করা হয় `macro_rules!` দিয়ে। এর সিনট্যাক্স দেখতে অনেকটা কম্পাইল-টাইম `match` এক্সপ্রেশনের মতো:

```rust
macro_rules! my_macro {
    ( matcher_pattern_1 ) => {
        expansion_code_1
    };
    ( matcher_pattern_2 ) => {
        expansion_code_2
    };
}
```

### ১. ম্যাক্রো ডেজিগনেটর (Designators)

ইনপুট প্যাটার্ন মেলানোর সময় ভ্যারিয়েবলের নামের পূর্বে `$` এবং পরে একটি **ডেজিগনেটর** যুক্ত করা হয়, যা নির্দেশ করে কোন ধরনের সিনট্যাক্স এলিমেন্ট প্রত্যাশিত:

| ডেজিগনেটর      | বিবরণ                                                          | উদাহরণের সাথে মিল                 |
| :------------- | :------------------------------------------------------------- | :-------------------------------- |
| **`$expr`**    | যেকোনো বৈধ রাস্ট এক্সপ্রেশন                                    | `42`, `1 + 2`, `get_val()`        |
| **`$ident`**   | যেকোনো আইডেন্টিফায়ার (ভ্যারিয়েবল বা এনাম ভ্যারিয়েন্টের নাম) | `Electronics`, `user_id`          |
| **`$ty`**      | যেকোনো রাস্ট টাইপ                                              | `u32`, `Vec<String>`, `Option<T>` |
| **`$pat`**     | যেকোনো প্যাটার্ন (যা `match` বা `let`-এ ব্যবহার হয়)           | `Some(x)`, `1..=10`               |
| **`$literal`** | যেকোনো লিটারেল মান                                             | `"hello"`, `100`, `true`          |
| **`$tt`**      | টোকেন ট্রি (যেকোনো ব্র্যাকেটবদ্ধ গ্রুপ বা একক টোকেন)           | `(1, 2)`, `{ ... }`               |

### ২. রিপিটিশন প্যাটার্ন (Repetition Patterns)

পরিবর্তনশীল সংখ্যক আর্গুমেন্ট গ্রহণ করতে (যেমন `vec![1, 2, 3]`), রাস্ট রিপিটিশন অপারেটর প্রদান করে:

- `$( ... ),*` — শূন্য বা ততোধিক উপাদান, কমা দিয়ে পৃথক।
- `$( ... ),+` — এক বা একাধিক উপাদান, কমা দিয়ে পৃথক।
- `$( ... )?` — শূন্য অথবা একটি উপাদান (ঐচ্ছিক)।
- `$(,)?` — লাইনের শেষে ঐচ্ছিক ট্রেইলিং কমা গ্রহণ করা।

```rust
macro_rules! sum_items {
    ( $( $val:expr ),* $(,)? ) => {
        {
            let mut total = 0;
            $(
                total += $val;
            )*
            total
        }
    };
}
```

কম্পাইলেশনের সময় `$( ... )*`-এর ভেতরের কোডটি প্রতিটি ম্যাচ হওয়া উপাদানের জন্য ক্রমান্বয়ে কোডে প্রতিলিপি (repeat) করা হয়!

## মিনিস্টোরের বাস্তব ডোমেন ম্যাক্রোসমূহ

চলুন দেখি মিনিস্টোরের [`src/macros.rs`](https://github.com/rimonmath/crafting-rust/blob/main/ministore/src/macros.rs) ফাইলে আমরা কী কী ম্যাক্রো তৈরি করেছি:

### ১. `product!` ম্যাক্রো: সহজ অবজেক্ট নির্মাণ ও এনাম শর্টহ্যান্ড

`product!` ম্যাক্রোতে একাধিক কম্পাইল-টাইম ব্রাঞ্চ রয়েছে:

- স্বয়ং-ব্যাখ্যামূলক নেমড প্যারামিটার ব্রাঞ্চ।
- পজিশনাল ব্রাঞ্চ যা সরাসরি এনাম ভ্যারিয়েন্ট নাম (`Electronics`, `ProductCategory::Electronics` লেখার প্রয়োজন নেই) গ্রহণ করে।
- স্টক উল্লেখ না করলে স্বয়ংক্রিয়ভাবে `stock = 1` ডিফল্ট নির্ধারণকারী ব্রাঞ্চ।
- স্ট্রিং লিটারেলকে স্বয়ংক্রিয়ভাবে `.to_string()` দিয়ে কনভার্ট করা।

```rust
#[macro_export]
macro_rules! product {
    // ব্রাঞ্চ ১: নেমড আর্গুমেন্ট স্টাইল
    (id: $id:expr, sku: $sku:expr, name: $name:expr, category: $cat:ident, price: $price:expr, stock: $stock:expr) => {
        $crate::models::Product::new(
            $id,
            $sku.to_string(),
            $name.to_string(),
            $crate::models::ProductCategory::$cat,
            $price,
            $stock,
        )
    };

    // ব্রাঞ্চ ২: পজিশনাল স্টাইল (ক্যাটাগরি শর্টহ্যান্ড ও স্টকসহ)
    ($id:expr, $sku:expr, $name:expr, $cat:ident, $price:expr, $stock:expr) => {
        $crate::models::Product::new(
            $id,
            $sku.to_string(),
            $name.to_string(),
            $crate::models::ProductCategory::$cat,
            $price,
            $stock,
        )
    };

    // ব্রাঞ্চ ৩: ডিফল্ট স্টক = ১ ব্রাঞ্চ
    ($id:expr, $sku:expr, $name:expr, $cat:ident, $price:expr) => {
        $crate::product!($id, $sku, $name, $cat, $price, 1)
    };
}
```

লক্ষ্য করুন, ব্রাঞ্চ ৩ নিজে কোড ডুপ্লিকেট না করে `$crate::product!(...)` দিয়ে ব্রাঞ্চ ২-কে কল করেছে!

### ২. `catalog!` ম্যাক্রো: ভ্যারিয়াডিক কালেকশন তৈরি

`catalog!` ম্যাক্রো দিয়ে এক বা একাধিক প্রোডাক্ট কমা দিয়ে সাজিয়ে এক লাইনে ক্যাটালগ তৈরি করা যায়:

```rust
#[macro_export]
macro_rules! catalog {
    ( $( $prod:expr ),* $(,)? ) => {
        {
            let mut catalog = $crate::catalog::Catalog::new();
            $(
                catalog.add_product($prod);
            )*
            catalog
        }
    };
}
```

ব্যবহার:

```rust
let catalog = catalog![
    product!(1, "SKU-001", "Laptop", Electronics, 120000, 5),
    product!(2, "SKU-002", "Pen", OfficeSupplies, 150), // স্টক অটোমেটিক ১
];
```

### ৩. `cart!` ম্যাক্রো: একাধিক সিনট্যাক্স স্টাইল সমর্থন

`cart!` ম্যাক্রো দেখায় কীভাবে একটি ম্যাক্রো দিয়ে সম্পূর্ণ ভিন্ন সিনট্যাক্স পার্স করা যায়:
১. সংক্ষিপ্ত টুপল স্টাইল: `(product_id, quantity, unit_price_cents)`
২. নেমড ফিল্ড স্টাইল: `(item: id, qty: count, price: cents)`

```rust
#[macro_export]
macro_rules! cart {
    // খালি কার্ট
    () => {
        $crate::models::ShoppingCart::new()
    };

    // টুপল স্টাইল: (product_id, quantity, unit_price_cents)
    ( $( ( $prod_id:expr, $qty:expr, $price:expr ) ),* $(,)? ) => {
        {
            let mut cart = $crate::models::ShoppingCart::new();
            $(
                cart.add_item($prod_id, $qty, $price);
            )*
            cart
        }
    };

    // নেমড স্টাইল: (item: $id, qty: $qty, price: $price)
    ( $( ( item: $prod_id:expr, qty: $qty:expr, price: $price:expr ) ),* $(,)? ) => {
        {
            let mut cart = $crate::models::ShoppingCart::new();
            $(
                cart.add_item($prod_id, $qty, $price);
            )*
            cart
        }
    };
}
```

### ৪. `calculate_total!` ম্যাক্রো: রিকার্সিভ ভ্যারিয়াডিক যোগফল

ম্যাক্রোতে রিকার্সিভ এক্সপ্যানশন ব্যবহার করে জটিল গাণিতিক অপারেশন করা যায় (হেড এবং টেইল আলাদা করে):

```rust
#[macro_export]
macro_rules! calculate_total {
    // বেস কেস ১: কোনো আর্গুমেন্ট না থাকলে ০
    () => {
        0u32
    };

    // বেস কেস ২: একক আর্গুমেন্ট থাকলে সেটিই রিটার্ন
    ($head:expr) => {
        $head
    };

    // ইনডাক্টিভ ধাপ: প্রথম উপাদান + বাকি উপাদানগুলোর রিকার্সিভ যোগফল
    ($head:expr, $($tail:expr),+ $(,)?) => {
        $head + $crate::calculate_total!($($tail),+)
    };
}
```

এক্সপ্যানশন যেভাবে ঘটে:

```rust
calculate_total!(100, 200, 300)
// ধাপে ধাপে বিস্তৃত হয়:
100 + calculate_total!(200, 300)
// এরপর:
100 + (200 + 300) = 600
```

### ৫. `assert_in_stock!` ম্যাক্রো: ডোমেন অ্যাসারশন

কাস্টম অ্যাসারশন ম্যাক্রো দিয়ে প্যানিক মেসেজে ডোমেন অবজেক্টের বিস্তারিত তথ্য সুন্দরভাবে প্রিন্ট করা যায়:

```rust
#[macro_export]
macro_rules! assert_in_stock {
    ($prod:expr, $required:expr) => {
        assert!(
            $prod.stock >= $required,
            "Stock assertion failed for SKU '{}' ({}): available {}, required {}",
            $prod.sku,
            $prod.name,
            $prod.stock,
            $required
        );
    };
}
```

## ম্যাক্রো হাইজিন এবং `$crate`-এর গুরুত্ব

যখন কোনো ম্যাক্রো `#[macro_export]` দিয়ে এক্সপোর্ট করা হয়, তখন অন্য মডিউল বা এক্সটার্নাল ক্রেট থেকেও এটি ব্যবহার করা যায়।

যদি আমাদের ম্যাক্রো ভেতরে `Product::new(...)` লিখে কোড তৈরি করত, তবে ব্যবহারকারীর ফাইলটিতে যদি আগে থেকে `use ministore::Product;` ইমপোর্ট করা না থাকত, তবে তার কোড কম্পাইল করত না!

এই সমস্যা দূর করতে ব্যবহৃত হয় **`$crate`**:

- `$crate` স্বয়ংক্রিয়ভাবে সেই ক্রেটের সম্পূর্ণ সঠিক পাথ নির্দেশ করে যেখানে ম্যাক্রোটি সংজ্ঞায়িত হয়েছে (যেমন লাইব্রেরির ভেতরে `crate` এবং বাইরে থেকে `::ministore`)।
- `$crate::models::Product` ব্যবহার করলে ব্যবহারকারী তার লোকাল ফাইলে কী ইমপোর্ট করেছেন তা নির্বিশেষে ম্যাক্রোটি সবসময় সঠিক টাইপ খুঁজে পায়।

## চেকপয়েন্ট ও সারসংক্ষেপ

২৫তম অধ্যায় সমাপ্তির মাধ্যমে আপনি রাস্ট মেটাপ্রোগ্রামিংয়ের জাদুকরী শক্তিতে দক্ষ হয়েছেন:

- আপনি শিখেছেন কীভাবে ডিক্লারেটিভ ম্যাক্রো কম্পাইল টাইমে টোকেন স্ট্রিম পার্স করে স্বয়ংক্রিয়ভাবে কোড লিখে দেয়।
- আপনি ডেজিগনেটর (`$expr`, `$ident`, `$ty`) এবং রিপিটিশন প্যাটার্ন (`$( ... ),*`) ব্যবহার করতে পারেন।
- আপনি মিনিস্টোরের জন্য অত্যন্ত বাস্তবসম্মত ডোমেন ডিএসএল তৈরি করেছেন (`product!`, `catalog!`, `cart!`, `calculate_total!`, এবং `assert_in_stock!`)।
- আপনি ম্যাক্রো হাইজিন এবং `$crate`-এর অপরিহার্য ভূমিকা উপলব্ধি করেছেন।

পরবর্তী অধ্যায়ে আমরা রাস্টের চূড়ান্ত সীমানা অন্বেষণ করব: **আনসেফ রাস্ট (Unsafe Rust)**, যেখানে আমরা দেখব কীভাবে রাস্ট মেমরির একেবারে নিম্ন স্তরের সাথে সরাসরি যোগাযোগ করে এবং কেন নিরাপদ অ্যাবস্ট্রাকশন রাস্টকে অনন্য করেছে!
